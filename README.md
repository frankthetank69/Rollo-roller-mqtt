**Projekt zum Rauf- und Runterfahren von Rollos**
Wireless anbindung via mqtt

Easy setup:
- vscode runterladen
- PlatformIO installieren
- überall ja drücken
- git runterladen
- den link unter dem button "Code" kopieren
- in einem Arbeitsverzeichnis deiner Wahl rechtsclick im windows explorer -> open git gui here
- "git clone [URL]" mit vorher kopiertem link eingeben und enter
- dann im VScode den ordner öffnen, viel spass!
